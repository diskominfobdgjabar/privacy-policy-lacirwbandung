# Laci RW Bandung Public Deletion Pages

The public web resource set of the Laci RW Bandung application that discloses
how personal information is handled and how account and data deletion can be
requested, declared together in the Play Console data safety form.

## Language

**Deletion Request Page**:
A permanently hosted public web page that explains and accepts requests to
delete an application account and its associated personal data.
_Avoid_: deletion portal, account cancellation URL, GDPR removal tool

**Deletion Request**:
A single verifiable deletion submission containing the requester's identifier
and contact verification details, delivered to the designated contact email.
_Avoid_: support ticket, complaint, takedown request

**Privacy Policy Page**:
The index public resource disclosing how personal information is collected,
used, disclosed, retained, and deleted.
_Avoid_: landing page, terms of service

**Deletion Resource Set**:
The pair of published resources (Privacy Policy Page + Deletion Request Page)
declared together in the Play Console data safety form.
_Avoid_: site map, policy bundle
